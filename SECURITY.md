# Security Policy

## Reporting a vulnerability

Do NOT open a public issue for suspected security vulnerabilities.

Instead, use one of these private channels:

1. **Preferred:** Report privately via GitHub: go to the **Security** tab of
   this repository and choose **Report a vulnerability**. This opens a private
   discussion with the maintainers and, if confirmed, becomes a draft security
   advisory where the fix is coordinated.
2. Email the security team at `security@im-juma-training-sb.example` if you
   cannot use GitHub private vulnerability reporting.

## What to include

- A description of the issue and its impact
- Steps to reproduce or proof-of-concept code
- Affected versions or commits, if known

## What to expect

| Stage | Target |
|-------|--------|
| Acknowledgement | 2 business days |
| Triage decision | 5 business days |
| Fix or mitigation plan | 30 days for high/critical |

We coordinate disclosure through a GitHub security advisory and credit
reporters who wish to be named. Please give us a reasonable window to ship
a fix before any public disclosure.
